# Smart Home Security Dashboard

A web-based smart home security application that simulates sensors and helps users monitor home security events through an interactive dashboard.

## Features

* User registration and login
* Door, window, and motion sensor simulation
* Security mode controls
* Intrusion alerts and event history
* Sensor status monitoring
* Responsive dashboard interface

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript
* Render
